## Before you ask

1. Check the project's README and documentation.
2. Search existing GitHub Issues and Discussions — your question may already be answered.

## Community support

Open a new issue only when the problem is reproducible and appropriate for public tracking. When opening one, please include:

- What you expected to happen and what actually happened.
- Steps to reproduce the issue.
- Relevant environment details (OS, version, framework versions, etc.).

## Security issues

For security vulnerabilities, follow [SECURITY.md](./SECURITY.md) instead of opening a public issue.

## Commercial support

For commercial consulting, custom software development or private support, use an officially published Angelito Systems contact channel.
