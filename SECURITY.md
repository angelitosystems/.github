# Security Policy

Security is a core part of how Angelito Systems builds software.

## Reporting a vulnerability

Please **do not** disclose exploitable vulnerabilities in public issues.

Use the repository's configured private security reporting channel when available. If none is configured yet, contact the project maintainers through an officially published contact method.

Include:
- affected repository and version;
- clear description;
- reproduction steps or proof of concept;
- impact assessment;
- suggested mitigation, if known.

Please avoid including personal data, production credentials or active secrets in reports.

## Responsible disclosure

We ask security researchers to allow reasonable time for investigation and remediation before public disclosure.
