# Code of Conduct

## Our standard

We expect everyone participating in Angelito Systems projects to be respectful, constructive and professional.

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, deliberate disruption and publication of private information without consent.

## Expected behavior

- Be respectful.
- Give and receive constructive feedback.
- Focus criticism on ideas and code, not people.
- Assume good intent while addressing problems directly.
- Protect private information.

Project maintainers may moderate discussions and contributions to keep communities healthy.

## Enforcement

Report concerns privately to the maintainers using the project's configured contact channel.
