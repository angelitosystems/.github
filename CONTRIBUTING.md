# Contributing to Angelito Systems

Thank you for contributing to projects maintained by Angelito Systems.

## Before opening a change

1. Read the repository's README and contribution guidelines.
2. Keep changes focused and maintainable.
3. Add or update tests when behavior changes.
4. Document public APIs and relevant configuration.
5. Never commit secrets, credentials or private data.

## Pull requests

Please explain:
- what changed;
- why it changed;
- how it was tested;
- any breaking or migration considerations.

Project-specific rules take precedence over this organization-level document.
