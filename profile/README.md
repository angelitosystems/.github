## Sobre Angelito Systems

**Angelito Systems S.A.C.** es una empresa peruana de tecnología e ingeniería de software.

Diseñamos, desarrollamos y evolucionamos productos digitales orientados a resolver necesidades reales mediante software moderno, automatización y arquitecturas escalables.

Nuestro trabajo comprende:

- Software a medida
- Plataformas SaaS
- Sistemas empresariales
- Aplicaciones web y móviles
- APIs e integraciones
- Inteligencia artificial
- Automatización de procesos
- Herramientas para desarrolladores

Nuestro enfoque prioriza la **seguridad, escalabilidad, mantenibilidad y experiencia de usuario**.

## Principios de Ingeniería

### Seguridad desde el diseño

La seguridad forma parte de la arquitectura desde el inicio, considerando autenticación, autorización, control de acceso, aislamiento de datos y protección de APIs.

### Arquitectura Escalable

Diseñamos sistemas capaces de crecer sin comprometer su estabilidad, rendimiento o mantenibilidad.

### Código Mantenible

Priorizamos estructuras claras, responsabilidades definidas, tipado, modularidad y decisiones técnicas sostenibles.

### Integridad de Datos

Protegemos la consistencia, trazabilidad y confiabilidad de la información procesada por nuestros sistemas.

### Experiencia de Usuario

El software debe simplificar procesos. Diseñamos interfaces claras, rápidas y enfocadas en las necesidades reales del usuario.

## Seguridad

Aplicamos prácticas de seguridad durante todo el ciclo de desarrollo:

- Autenticación y autorización
- Control de acceso basado en roles y permisos
- Aislamiento de datos
- Validación de entradas
- Diseño seguro de APIs
- Auditoría y trazabilidad
- Protección de bases de datos
- Gestión segura de sesiones
- Gestión de dependencias
- Prácticas seguras de despliegue

Si encuentras una posible vulnerabilidad en un producto o servicio de Angelito Systems, evita publicarla mediante un GitHub Issue.

Puedes reportarla de forma privada a:

**support@angelitosystems.net**
